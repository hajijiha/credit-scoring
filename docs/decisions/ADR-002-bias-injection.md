# ADR-002. 편향 주입 방식 (bias_ratio)

| 버전 | 날짜 | 변경 내용 |
|---|---|---|
| v1 | 2026-09-08 | 최초 작성. 편향 대상 = female / **55+** |
| **v2 (현행)** | 2026-09-08 | 편향 대상을 female / **20-34** 로 변경. `bias_shift_per_ratio` 0.1 → 0.3 상향 |

> **유효 `bias_ratio` 범위 (ADR-001 v2 반영):** 0 ~ 0.3.
> ADR-001 v2 로 생성 상관이 0.31~0.35 로 낮아지면서 편향 하향에 쓸 여유가 줄었다.
> `bias_ratio = 0.4` 부터 telecom/utility 의 target 상관이 0.30 아래로 내려가 SPEC §4 를 위반한다.
> (GMSC 149,999행 실측: 0.3 → 0.3195/0.3107, 0.4 → 0.3014/0.2932)

## 결정 (v2)

민감속성 컬럼 `gender`(male/female), `age_group`(20-34 / 35-54 / 55+) 을 생성한다.
그리고 **female 집단과 20-34 집단**에 대해 `telecom_payment_rate`, `utility_payment_rate` 값을
`bias_ratio × bias_shift_per_ratio` 만큼 하향 조정한다.
두 집단에 모두 속하면 하향폭이 가산된다.

**타겟(SeriousDlqin2yrs)은 절대 건드리지 않는다.**

- `bias_shift_per_ratio = 0.3` (config/config.yaml). 기본 `bias_ratio = 0.1` → 집단당 0.03 하향.

## 근거

### 편향이 피처 측정 편향이어야 하는 이유 (v1 부터 유지)

주입하는 편향은 "피처 측정 편향(measurement bias)" 이다.
실제 부도 위험은 같은데 대안 데이터 상의 관측치만 특정 집단에서 낮게 찍히는 상황이라야,
Fairlearn Mitigation 전/후 비교가 "잘못된 측정을 보정했다"는 의미를 가진다.

### 편향 대상을 55+ 에서 20-34 로 바꾼 이유 (v2)

ADR-001 에 따라 대안 피처는 연령을 신호원 중 하나로 사용한다. 그 결과 편향을 전혀 주입하지 않은
상태(`bias_ratio = 0`)에서도 55+ 의 `telecom_payment_rate` 평균이 20-34 보다 **+0.082 높다**.
여기에 55+ 를 하향시키는 편향을 얹으면, 주입한 편향이 자연 격차를 **상쇄하는** 방향으로 작용한다.
실제로 v1 구현에서 55+ − 20-34 격차는 bias_ratio 0 / 0.1 / 0.5 에서 +0.082 → +0.072 → +0.032 로
줄어들었다. "편향을 키웠는데 집단 격차가 줄어드는" 결과가 되어 리포트 서사가 성립하지 않는다.

편향 대상을 20-34 로 바꾸면 자연 격차와 주입 편향이 **같은 방향으로 누적**되어, bias_ratio 를 올릴수록
연령대 격차가 단조 증가한다. Mitigation 전/후 비교도 해석 가능해진다.

도메인 서사와도 맞다. 사회초년생은 통신·공과금 납부 이력 자체가 짧아 대안 데이터에서 구조적으로
불리하게 측정되며, 이는 씬파일러 문제의 현실적인 형태다(SPEC §1: 사회초년생·프리랜서·주부).

### 하향폭을 0.1 → 0.3 으로 올린 이유 (v2)

`bias_shift_per_ratio = 0.1` 에서는 기본 `bias_ratio = 0.1` 기준 하향폭이 0.01 이다.
`telecom_payment_rate` 의 값 범위가 0.60~1.00 인 점을 감안하면 피처 표준편차 대비 너무 작아
DI Ratio 에 유의한 집단 격차가 잡히지 않을 위험이 있다. 0.3 으로 올려 기본 하향폭을 0.03 으로 둔다.
모델 학습 후 실제 DI Ratio 를 보고 재조정한다.

## 버린 대안

- **타겟 왜곡(특정 집단의 부도 라벨을 뒤집기)**: 진짜 부도율 집단 차이와 주입된 편향을 구분할 수 없게 된다.
  공정성 지표가 나빠져도 그것이 데이터 편향 탓인지 실제 위험 차이 탓인지 논증이 불가능하다.
- **집단별 샘플 수 불균형 주입**: 표본 편향은 재가중치로 쉽게 해소되어 Mitigation 비교가 밋밋해진다.
- **(v2 검토) 55+ 를 그대로 두고 해석에서만 설명**: 자연 격차와 주입 편향이 반대 방향이라는 사실을
  매번 단서로 달아야 하고, 공정성 지표의 개선/악화 방향이 뒤집혀 리포트 서사가 꼬인다.
- **(v2 검토) 대안 피처의 연령 가중치 축소**: 자연 격차는 줄지만 ADR-001 의 상관계수 0.3~0.5 조건을
  다시 맞춰야 하고, 소득 신호 비중이 커져 생성 로직의 성격이 달라진다. 비용 대비 이득이 작다.
