# ADR-002. 편향 주입 방식 (bias_ratio)

## 결정
민감속성 컬럼 `gender`(male/female), `age_group`(20-34 / 35-54 / 55+) 을 생성한다.
그리고 **female 집단과 55+ 집단**에 대해 `telecom_payment_rate`, `utility_payment_rate` 값을
`bias_ratio × 0.1` 만큼 하향 조정한다 (기본 `bias_ratio = 0.1` → 1% 하향).

**타겟(SeriousDlqin2yrs)은 절대 건드리지 않는다.**

## 근거
주입하는 편향이 "피처 측정 편향(measurement bias)" 이어야 한다.
즉 실제 부도 위험은 같은데 대안 데이터 상의 관측치만 특정 집단에서 낮게 찍히는 상황이라야,
Fairlearn Mitigation 전/후 비교가 "잘못된 측정을 보정했다"는 의미를 가진다.

## 버린 대안
- **타겟 왜곡(특정 집단의 부도 라벨을 뒤집기)**: 진짜 부도율 집단 차이와 주입된 편향을 구분할 수 없게 된다.
  공정성 지표가 나빠져도 그것이 데이터 편향 탓인지 실제 위험 차이 탓인지 논증이 불가능하다.
- **집단별 샘플 수 불균형 주입**: 표본 편향은 재가중치로 쉽게 해소되어 Mitigation 비교가 밋밋해진다.
