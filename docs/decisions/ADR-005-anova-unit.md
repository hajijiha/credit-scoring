# ADR-005. 통계 검정의 관측 단위

## 결정
모델 성능 비교(ANOVA)의 관측치는 `RepeatedStratifiedKFold(n_splits=5, n_repeats=4)` 로 만든다.
→ 그룹(모델)당 AUC 관측치 **n = 20**.

## 근거
단일 5-fold CV 는 그룹당 n=5 다. 이 표본 크기로는
- 검정력이 낮아 실제 차이를 잡아내지 못하고,
- 정규성·등분산 가정을 확인할 근거조차 부족하다.

5×4 반복으로 n=20 을 확보하면 사후검정(Tukey HSD)과 효과크기 보고까지 무리 없이 이어진다.

## 버린 대안
- **단일 5-fold (n=5)**: 위 사유로 기각.
- **부트스트랩 리샘플 100회**: 관측치는 많아지지만 서로 강하게 종속되어 ANOVA 의 독립성 가정을 위반한다.
- **n_repeats 를 10 이상으로**: 계산 비용이 선형으로 늘고, n=20 이면 목적에 충분하다.

> 주의: 반복 CV 관측치도 완전 독립은 아니다. 결과 보고 시 이 한계를 명시한다.
