# ADR-006. 메인 데이터셋 선정

## 결정
메인 데이터셋은 **GMSC (Give Me Some Credit, 150,000행)** 로 한다.
German Credit 은 `src/data` 의 loader 에 **함수만 정의**해 두고 메인 분석에는 사용하지 않는다.

## 근거
- German Credit 은 1,000건이다. ADR-005 의 반복 CV, 그리고 성별×연령대로 쪼개는 공정성 분석까지 가면
  하위 집단 표본이 수십 건 단위로 떨어져 지표가 불안정해진다.
- GMSC 는 150,000행에 부도율 약 6.7% 로, 불균형 처리·공정성 하위집단 분석·ANOVA 모두를 감당한다.

## 버린 대안
- **German Credit 을 메인으로**: 민감속성이 원본에 포함돼 있다는 장점이 있으나 표본 부족으로 기각.
- **두 데이터셋 동등 병행**: 분석·문서 분량이 두 배가 되고 결론이 흐려진다.
  loader 함수만 남겨 필요 시 보조 검증에 쓸 수 있게 한다.
