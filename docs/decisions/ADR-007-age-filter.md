# ADR-007. 연령 이상치 처리 (age < 18 행 제거)

## 결정
GMSC 로드 시 `age < 18` 인 행을 **제거**한다. 대체하지 않는다.
제거 건수는 로더에서 로그로 남긴다.

## 근거
- `age` 는 ADR-002 에서 **보호 속성**(`age_group`: 20-34 / 35-54 / 55+)의 원천 컬럼이다.
  18세 미만 값은 이 세 구간 어디에도 배정할 수 없다. 그룹 배정이 불가능한 행을 남겨두면
  공정성 지표 계산에서 처리되지 않는 잔여 집단이 생긴다.
- 신용평가는 성년을 대상으로 하는 업무다. 미성년 연령을 가진 행은 도메인상 평가 대상이 아니다.
- GMSC 원본 `age` 는 최소 0 을 포함한다(관측: min=0, max=109). 0 은 실제 연령이 아니라 결측·입력 오류다.

## 버린 대안
- **중앙값 대체**: 존재하지 않는 연령을 만들어 넣는 것이고, 그 가짜 연령이 그대로 `age_group` 에
  배정되어 공정성 분석 대상 집단을 오염시킨다. 편향 측정 결과를 신뢰할 수 없게 된다.
- **결측 처리 후 유지**: 민감속성이 결측인 행은 Fairlearn 지표 계산에서 어차피 제외해야 한다.
  파이프라인 뒤쪽에서 조용히 빠지는 것보다 로더에서 명시적으로 제거하고 건수를 로그로 남기는 편이 낫다.
- **0 만 제거하고 1~17 은 유지**: 기준이 자의적이고 `age_group` 배정 문제가 그대로 남는다.
