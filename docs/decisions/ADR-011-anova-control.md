# ADR-011. ANOVA 검정의 통제 방식

## 문제

`data/processed/fold_auc.csv` 에는 360개의 fold AUC 가 있다.

```
18 조합 (알고리즘 3 × 피처그룹 3 × 불균형처리 2) × RepeatedStratifiedKFold(5×4) 20 fold
```

피처 그룹별로 세면 그룹당 120개다. 그러나 이 120개는 **피처 그룹의 반복 관측이 아니다.**
알고리즘 3종과 불균형 처리 2종이 안에 섞여 있어, 그대로 One-way ANOVA 에 넣으면
피처 그룹 효과와 알고리즘 효과가 교락(confounded)된다.
집단 내 분산이 "같은 조건의 fold 간 변동"이 아니라 "알고리즘이 다른 데서 오는 변동"까지
포함하게 되어 F 통계량의 의미가 흐려진다.

## 결정

**두 검정 모두 나머지 요인을 하나의 수준으로 고정한다.**

| 검정 | 요인(비교 대상) | 고정하는 요인 | 그룹당 n |
|---|---|---|---|
| 검증 1 | 피처 그룹 (traditional / alternative / combined) | 알고리즘 = `xgboost`, 불균형 = `class_weight` | **20** |
| 검증 2 | 알고리즘 (LR / XGBoost / LightGBM) | 피처 그룹 = `combined`, 불균형 = `class_weight` | **20** |

고정 값은 `config.models.champion` 의 최종 채택 조합을 따른다.
관측 단위는 ADR-005 가 정한 RepeatedStratifiedKFold(5×4) = 20 이며, 이 결정으로
그룹당 n 이 정확히 20 이 되어 ADR-005 와 일관된다.

보조로 **전체 360개를 쓴 결과도 함께 산출**하되, 교락이 있음을 명시하고 참고치로만 보고한다
(`scope="pooled"`).

## 근거

- **교락 제거.** 검증 1 의 질문은 "대안 데이터를 넣으면 성능이 오르는가"다. 알고리즘을 고정해야
  집단 간 차이를 피처 구성 탓으로 돌릴 수 있다.
- **ADR-005 와의 일관성.** ADR-005 는 그룹당 n=20 을 확보하려고 반복 CV 를 도입했다.
  120개를 쓰면 표본이 늘어난 것처럼 보이지만 독립 관측이 늘어난 것이 아니다.
- **고정 수준의 선택.** 최종 채택 조합(`xgboost` / `combined` / `class_weight`)을 기준으로 삼으면,
  검정 결과가 실제로 배포되는 모델의 구성에 대한 진술이 된다.

## 한계 (결과 해석에 반드시 명시)

- 반복 CV 의 fold 들은 같은 데이터를 재사용하므로 **완전히 독립이 아니다.** ANOVA 의 독립성 가정을
  엄밀히는 만족하지 않으며, p-value 가 실제보다 작게 나오는 경향이 있다.
- 따라서 **p-value 보다 효과크기(η²)와 집단 평균 차이의 크기**를 우선해 해석한다.
- 고정 수준을 바꾸면 결과가 달라질 수 있다. 리포트에는 고정 조건을 반드시 함께 적는다.

## 버린 대안

- **360개 전부를 One-way ANOVA 에 투입**: 위의 교락 문제. 참고치로만 병기한다.
- **Two-way ANOVA (피처그룹 × 알고리즘)**: 교락은 해소되지만 SPEC §5 는 One-way 두 건을 요구한다.
  교호작용 분석은 SPEC 의 보너스 과제 3번에 해당하므로 그쪽에서 다룬다.
- **조합별 평균을 관측치로 사용(그룹당 n=6)**: 독립성은 나아지지만 ADR-005 가 기각한
  소표본 문제로 되돌아간다.
