# 요약 (Executive Summary)

금융 이력이 부족한 **씬파일러**를 대상으로, 실제 신용 데이터(GMSC)에 대안 데이터 5개 변수를 시뮬레이션으로
결합해 신용위험 모델을 만들고, 그 판단의 **설명가능성**(SHAP)과 **집단 공정성**(Fairlearn)을 함께 검증했다.
결과는 FastAPI 심사 API · Streamlit 대시보드 · MLflow 로 구성된 시스템으로 제공된다.

## 결론

> 전통 신용정보가 결손된 씬파일러에게 대안 데이터는 통계적으로 유의한 AUC 개선을 제공한다
> (씬파일러 +0.152, 전체 +0.110; ANOVA F=4245.65, p<0.001, η²=0.9933).
> 그러나 보호 속성을 학습에서 제외해도 편향은 대안 피처를 경유해 전파되며,
> 그 경로는 **측정 편향(성별)** 과 **피처 내재 상관(연령대)** 두 종류로 구분된다.
> 후자는 편향 원인 제거가 예측력 손실을 수반하므로 **사후 임계값 조정이 현실적 대응**이다.

## 세 질문에 대한 답

**Q1 성능 — 대안 데이터는 전통 정보가 부족한 사람에게 더 크게 기여한다.**
씬파일러 유형별 uplift 가 `history_only` +0.1013 < `missing_only` +0.1681 < `both` +0.1883 으로 전통 피처
결손이 클수록 커지고, 통합 모델은 세그먼트 간 AUC 편차를 0.1131 → 0.0195 로 줄인다. 알고리즘은 XGBoost 와
LightGBM 이 통계적으로 구분되지 않아(p_adj = 0.6468) 설명 도구 성숙도로 XGBoost 를 골랐다.

**Q2 설명가능성 — 설명의 가치는 경계 사례에서 드러나고, 충실성은 따로 설계해야 한다.**
부도 확률 0.375 로 거절된 씬파일러(실제로는 비부도)는 통신비 · 공과금 납부율을 각 2%p 올리면 승인된다.
반면 대안 피처가 들어가며 소득 · 연령의 SHAP 부호가 뒤집히는 설명 소거, 연체 '기록 없음'을 숫자로 다룰 때의
"−1회로 적습니다" 같은 오류는 정확한 SHAP 값에서도 틀린 문장이 나올 수 있음을 보였다.

**Q3 공정성 — 보호 속성을 빼도 차별은 사라지지 않는다.**
`bias_ratio = 0` 에서 성별 DI 는 1.0030 으로 균등하지만 연령대 min/max DI 는 이미 0.7840 이다. 성별 격차는
주입한 측정 편향, 연령대 격차는 대안 피처 생성 구조에 내재한 상관에서 온다. ThresholdOptimizer 로 EO FPR 차이를
0.1487 → 0.0155 로 줄였지만, 그 대가로 age_group 기준 고객의 5.83% 가 확률적으로 결정되고 보호 속성을
결정 시점에 직접 사용하게 된다.

## 해석할 때 주의할 점

- **절대 수치가 아니라 상대 비교로 읽는다.** AUC 0.9453 은 명세의 상관 요건(0.3~0.5)을 부도율 6.68% 에 적용해
  생긴 구조적 상한이다(10.1절).
- **성별 결과는 설계의 확인이다.** 성별은 타겟과 독립인 무작위 합성이다(10.4절).
- **η² > 0.95 와 극단적으로 작은 p-value 는 반복 CV 설계의 산물이다.** 판단은 평균 차이의 크기로 한다(8.5절).
- 검증 과정에서 발견하고 수정한 오류 12건과, 리포트 인용 수치를 산출물에서 다시 계산하는 대조 절차를
  9장과 부록 E 에 기록했다.
