# 공정성 검증: proxy discrimination 과 완화의 트레이드오프

> 리포트 §공정성 검증에 사용할 자료. 근거 결정은
> [ADR-002 v3](../decisions/ADR-002-bias-injection.md), [ADR-004 v2](../decisions/ADR-004-mitigation.md),
> [ADR-008](../decisions/ADR-008-protected-attributes.md).

## 1. 실험 설계: 직접 경로를 차단한다

이 프로젝트의 공정성 질문은 "모델이 성별·연령을 보고 차별하는가"가 아니다. 그건 자명하다.
질문은 **"보호 속성을 아예 보여주지 않아도 차별이 일어나는가"** 다.

그래서 세 겹으로 설계했다.

1. **편향은 피처에만, 타겟에는 넣지 않는다** (ADR-002).
   `female` 과 `20-34` 집단의 `telecom_payment_rate` / `utility_payment_rate` 관측치를
   `bias_ratio × 0.3` 만큼 낮춘다. 실제 부도 라벨은 건드리지 않는다.
   즉 **실제 위험은 같은데 관측만 나쁘게 찍히는** 측정 편향이다.
2. **보호 속성을 학습 피처에서 제외한다** (ADR-008).
   `gender` 와 `age_group` 은 데이터에 남지만 모델 입력 `X` 에는 들어가지 않는다.
   모델이 쓰는 것은 전통 피처 13개 + 대안 피처 5개뿐이다.
3. **완화는 후처리로 한다** (ADR-004).
   같은 모델·같은 예측 확률 위에서 임계값만 바꾸므로 전/후 비교가 깔끔하다.

이 구성에서 집단 간 승인율 격차가 관측된다면, 그것은 **전적으로 대안 피처를 경유해 전파된
간접 편향(proxy discrimination)** 이다. 모델은 성별도 연령대도 본 적이 없기 때문이다.

## 2. 결과: 편향은 전파된다 — 단, 두 속성의 원인이 다르다

챔피언 모델(`xgboost | combined | class_weight`, `bias_ratio = 0.3`)의 test 22,500행 결과다.
전체 승인율 0.7940, 승인 임계 0.30.

| 보호 속성 | 집단별 승인율 | DI (보호/나머지) | DI (min/max) | EO TPR차 | EO FPR차 |
|---|---|---:|---:|---:|---:|
| gender | female 0.7603 / male 0.8272 | 0.9191 | 0.9191 | 0.0350 | 0.0696 |
| age_group | 20-34 **0.6789** / 35-54 0.7438 / 55+ **0.8764** | 0.8375 | **0.7747** | 0.0862 | **0.1487** |

모델은 `gender` 도 `age_group` 도 입력으로 받은 적이 없다. 그런데도 20-34 집단의 승인율이
55+ 보다 **20%p 낮고**, min/max 기준 DI 0.7747 은 4/5 규칙(0.8)에 미달하며,
Equalized Odds FPR 차이 0.1487 은 기준 0.10 을 넘는다. **간접 편향이 실재한다.**

### 2-1. `bias_ratio` 민감도: 두 속성의 원인이 갈린다

각 수준마다 데이터를 재생성하고 챔피언 조합을 다시 학습해 측정했다.

| bias_ratio | 하향폭 | female | male | **gender DI** | 20-34 | 35-54 | 55+ | age DI(min/max) | 전체 승인율 | test AUC |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 0.0 | 0.000 | 0.8055 | 0.8031 | **1.0030** | 0.6947 | 0.7531 | 0.8861 | 0.7840 | 0.8043 | 0.9497 |
| 0.1 | 0.030 | 0.7805 | 0.8215 | 0.9502 | 0.6838 | 0.7508 | 0.8844 | 0.7732 | 0.8011 | 0.9485 |
| 0.2 | 0.060 | 0.7698 | 0.8283 | 0.9293 | 0.6803 | 0.7494 | 0.8825 | 0.7709 | 0.7992 | 0.9465 |
| 0.3 | 0.090 | 0.7603 | 0.8272 | **0.9191** | 0.6789 | 0.7438 | 0.8764 | 0.7747 | 0.7940 | 0.9453 |

**성별**: `bias_ratio` 를 올릴수록 DI 가 1.0030 → 0.9502 → 0.9293 → 0.9191 로 **단조 감소**한다.
편향을 주입하지 않으면(0.0) DI 가 1.0030 으로 완전한 균등이다.
즉 성별 격차는 **전적으로 주입된 측정 편향이 대안 피처를 경유해 전파된 결과**다.
SPEC §4 의 "`bias_ratio` 를 조정하면 성별/연령대별 승인율 편향이 변경된다" 요건이 이 표로 실증된다.

**연령대**: `bias_ratio = 0` 에서 이미 min/max DI 가 **0.7840 으로 0.8 미만**이고,
0.3 까지 올려도 0.7747 로 거의 변하지 않는다(−0.009).
연령대 격차는 주입 편향이 아니라 **ADR-001 의 설계에서 온다.**
대안 피처는 소득·연령을 신호원으로 생성되므로(`nuisance = 0.7·소득 + 0.3·연령`)
연령이 높을수록 대안 피처 값이 좋게 나온다. 모델이 연령대를 보지 않아도
대안 피처를 통해 연령 정보를 간접적으로 학습한다.

> **이 대비가 이 실험의 핵심 결과다.**
> 같은 "간접 편향"이라도 성별은 **의도적으로 주입한 측정 편향**에서,
> 연령대는 **피처 생성 구조에 내재한 상관**에서 왔다.
> 실무에서 후자가 더 까다롭다. 편향을 주입한 적이 없어도, 대안 데이터가 보호 속성과
> 자연스럽게 상관되어 있으면 그 상관이 그대로 결정에 실린다.

### 2-2. DI Ratio 정의에 따라 판정이 갈린다

- SPEC §1 용어 정의: "보호 집단의 승인율을 비보호 집단의 승인율으로 나눈 비율" → 0.8375, **충족**
- 규제 실무의 관행(최저 집단 / 최고 집단) → 0.7747, **미달**

같은 데이터에서 결론이 뒤집히므로 **두 값을 모두 보고한다.**

## 3. 완화: 무엇이 좋아지고 무엇을 잃는가

### 3-1. 완화 결과

`ThresholdOptimizer(constraints="equalized_odds", objective="balanced_accuracy_score")`,
valid 로 적합하고 test 로 평가했다.

| 지표 | gender 전 → 후 | age_group 전 → 후 |
|---|---|---|
| DI Ratio | 0.9191 → **0.9942** | 0.8375 → **0.9433** |
| EO TPR차 | 0.0350 → 0.0106 | 0.0862 → 0.0384 |
| EO FPR차 | 0.0696 → 0.0064 | **0.1487 → 0.0155** |
| 전체 승인율 | 0.7940 → 0.8196 | 0.7940 → 0.8492 |
| AUC | 0.9453 → 0.8736 | 0.9453 → 0.8592 |

기준 위반이던 age_group 의 EO FPR 차이가 0.1487 → 0.0155 로 해소된다.
승인율은 0.79 → 0.82~0.85 로 소폭 상승하는 데 그쳐 심사 기능이 유지된다.

### 3-2. AUC 하락은 성능 저하가 아니다

완화 후 AUC 가 0.9453 → 0.86~0.87 로 떨어진다. **이것은 모델 성능이 나빠진 것이 아니다.**

완화 전 출력은 0~1 사이의 **부도 확률**이고, AUC 는 이 확률의 **순위 품질**을 재는 지표다.
완화 후 출력은 승인/거절이라는 **이진 결정**이다. 확률 순위 정보가 사라졌으므로
이진 벡터로 계산한 AUC 는 원리적으로 낮아진다
(이진 예측의 AUC 는 `(TPR + TNR) / 2`, 즉 balanced accuracy 와 같다).

모델의 가중치도, 확률 출력도 바뀌지 않았다. 바뀐 것은 집단별 임계값뿐이다.

> **따라서 완화 전/후 비교는 AUC 가 아니라 DI Ratio, Equalized Odds, 승인율로 판단한다.**
> AUC 는 완화 전 모델의 판별력을 보고할 때만 쓴다.

### 3-3. 목적함수를 바꾼 이유 (ADR-004 v2)

`objective="accuracy_score"` 로 적합했을 때는 승인율이 **0.8011 → 0.955** 로 뛰었다.
부도율이 6.7% 인 데이터에서 정확도를 최대화하면 "거의 전부 승인"이 최적해이기 때문이다.

공정성 지표는 좋아 보였지만(DI 1.0000) 이는 **모두를 승인하면 집단 간 격차가 사라진다**는
자명한 사실일 뿐이다. 심사 기능을 버린 대가로 얻은 공정성은 대출 심사 시스템으로 방어할 수 없다.

`balanced_accuracy_score` 는 TPR 과 TNR 의 평균이라 소수 클래스를 무시할 수 없다.
전부 승인하면 TPR 이 0 이 되어 목적함수가 0.5 로 떨어지므로 승인율이 현실 범위에 유지된다.
실제로 승인율이 0.955 → **0.82~0.85** 로 돌아왔고, AUC 손실도 0.739 → **0.86~0.87** 로 줄었다.

## 5. 결론

전통 신용정보가 결손된 씬파일러에게 대안 데이터는 통계적으로 유의한 AUC 개선을 제공한다
(씬파일러 집단 **+0.152**, 전체 **+0.110**; One-way ANOVA F=4245.65, **p < 0.001**, η²=0.9933).
개선폭은 전통 피처의 결손이 클수록 커진다
(`thin:both` +0.188 > `thin:missing_only` +0.168 > `thin:history_only` +0.101 > 일반 +0.095).

그러나 **보호 속성을 학습에서 제외해도(ADR-008) 편향은 대안 피처를 경유해 전파된다.**
그 경로는 두 종류로 구분된다.

| 경로 | 대상 | 근거 | 특징 |
|---|---|---|---|
| **측정 편향** | 성별 | `bias_ratio=0` 에서 DI 1.0030 → 0.3 에서 0.9191 (단조 반응) | 주입한 편향이 원인. 원인을 제거하면 사라진다 |
| **피처 내재 상관** | 연령대 | `bias_ratio=0` 에서 이미 min/max DI 0.7840, 0.3 에서 0.7747 (거의 불변) | 대안 피처가 연령을 신호원으로 쓰는 설계에서 옴 |

**후자는 편향 원인 제거가 예측력 손실을 수반한다.** 연령대 격차를 없애려면 대안 피처에서
연령 신호를 빼야 하는데, 그러면 피처의 예측력 자체가 줄어든다(ADR-001 v2 의 w 레버 실험에서
확인한 것과 같은 구조다). 데이터를 고치는 대신 **사후 임계값 조정(ThresholdOptimizer)이
현실적 대응**이며, 실제로 EO FPR 차이를 0.1487 → 0.0155 로 낮추면서 승인율을
0.7940 → 0.8492 로 유지했다.

## 6. 리포트에 함께 적을 한계

- 절대 수치는 시뮬레이션 데이터의 산물이다. 실제 대안신용평가에서 이 크기의 편향이
  관측된다는 뜻이 아니다(ADR-001 "한계" 절 참조).
- 반복 CV fold 는 완전 독립이 아니므로 통계 검정의 p-value 는 보수적으로 읽는다(ADR-011).
- `ThresholdOptimizer` 는 예측을 확률적으로 섞는다(interpolation). 같은 고객에게 항상 같은
  결정이 나오지 않을 수 있으며, 실제 금융 서비스에서는 별도의 검토가 필요하다.
- 대안 피처의 target 상관은 SPEC §4 하한(0.30)에 근접해 있다(최소 여유 0.0099, ADR-001 "한계").
  F1~F5 결과는 현재 데이터로 동결했다.
