# 대안 데이터 시뮬레이터: 진단과 보정

> 리포트 §시뮬레이터 설계에 사용할 자료. 근거 결정은 [ADR-001 v2](../decisions/ADR-001-simulator.md),
> [ADR-010](../decisions/ADR-010-thin-filer-types.md).

## 1. 문제 발견

SPEC §4 는 대안 변수와 Target 의 상관계수를 0.3 ~ 0.5 로 요구한다.
이 요건을 문자 그대로 구현한 v1 시뮬레이터로 모델을 학습하자 다음 결과가 나왔다.

| 피처 그룹 | v1 test AUC (LightGBM, class_weight) |
|---|---:|
| traditional_only | 0.834 |
| alternative_only | **0.996** |
| combined | **0.9999** |

대안 데이터만으로 부도를 거의 완벽히 분리한다. 씬파일러 집단 AUC uplift 도 **+0.238** 로
SPEC 목표(+0.03)의 8배였다. 신용평가 모델로 방어할 수 없는 수치다.

## 2. 원인 분석

### 2-1. 개별 상관은 규격 안에 있었다

| 변수 | \|corr\| | 규격 0.30~0.50 |
|---|---:|---|
| telecom_payment_rate | 0.4855 | 충족 |
| utility_payment_rate | 0.4398 | 충족 |
| spending_consistency | 0.3991 | 충족 |
| regular_payment_count | 0.3504 | 충족 |
| app_login_frequency | 0.3031 | 충족 |

즉 규격 위반이 아니었다. 문제는 **결합**에 있었다.

### 2-2. 부도율 6.68% 에서 상관 0.3~0.5 는 매우 강한 조건

이진 타겟에 대한 점이연상관 `r` 은 집단 분리 효과크기로 환산된다.

```
d = r / sqrt( p(1-p) (1 - r^2) ),   p = 0.0668
```

| \|corr\| | Cohen's d | 단일 변수만의 AUC |
|---:|---:|---:|
| 0.15 | 0.60 | 0.666 |
| 0.20 | 0.81 | 0.718 |
| 0.25 | 1.03 | 0.768 |
| 0.30 | 1.26 | 0.813 |
| 0.35 | 1.49 | 0.855 |
| 0.40 | 1.75 | 0.892 |
| 0.45 | 2.02 | 0.923 |
| 0.49 | 2.25 | **0.944** |

**대안 변수 하나가 전통 모델 전체(0.834)를 이긴다.**

### 2-3. 조건부 독립이 정보를 그대로 합산시켰다

v1 은 각 변수의 비(非)타겟 성분을 서로 독립인 개별 노이즈로 채웠다.
그 결과 타겟을 조건으로 하면 다섯 변수가 거의 독립이었다.

| | v1 | v2 |
|---|---:|---:|
| 클래스 내부 평균 상관 (class 0) | 0.19 | **0.69** |
| 클래스 내부 평균 상관 (class 1) | 0.14 | 0.64 |

조건부 독립 가정에서는 효과크기가 제곱합으로 누적된다.

| 변수 | Cohen's d |
|---|---:|
| telecom_payment_rate | 2.224 |
| utility_payment_rate | 1.961 |
| spending_consistency | 1.743 |
| regular_payment_count | 1.498 |
| app_login_frequency | 1.273 |
| **결합 d = sqrt(Σ d²)** | **3.962** |

이론 AUC = Φ(3.962 / √2) = **0.9975**. 관측값 0.9959 와 일치한다.
따라서 v1 의 결과는 구현 버그가 아니라 **가정의 결과**였다.

## 3. 보정: 공유 잠재요인 도입 (ADR-001 v2)

현실에서는 성실한 사람이 통신비도 공과금도 잘 낸다. 이 공통 요인을 명시적으로 넣는다.

```
v_i    = rho_i * t_z + sqrt(1 - rho_i^2) * m_i
m_i    = w * shared + sqrt(1 - w^2) * eps_i      (t_z 에 직교화 후 표준화)
shared = standardize(0.6 * nuisance + 0.8 * common_noise)
```

`shared` 가 다섯 변수에 함께 실리므로 타겟을 조건으로 해도 변수들이 서로 상관을 갖고,
정보가 단순 합산되지 않는다.

### 3-1. `latent_factor_strength` (w) 레버 실험

생성 상관 0.31~0.35 고정, LightGBM class_weight, train fit → test 평가.

| w | 클래스 내부 평균 상관 | traditional | alternative | combined |
|---:|---:|---:|---:|---:|
| 0.85 | 0.692 | 0.8338 | 0.8963 | **0.9470** |
| 0.90 | 0.782 | 0.8338 | 0.8870 | 0.9420 |
| 0.92 | 0.821 | 0.8338 | 0.8843 | 0.9412 |
| 0.94 | 0.861 | 0.8338 | 0.8798 | 0.9396 |

**w 를 아무리 키워도 combined 는 0.94 아래로 내려가지 않는다.**
공유 요인은 대안 변수들 *사이의* 중복만 늘릴 뿐, 전통 피처와의 상보성은 줄이지 못하기 때문이다.

### 3-2. 생성 상관 하한 실험

w = 0.85 고정.

| 생성 상관 | 실제 \|corr\| | alternative | combined | SPEC §4 (0.3~0.5) |
|---|---|---:|---:|---|
| **0.31~0.35 (채택)** | 0.309~0.346 | 0.8963 | **0.9470** | 충족 |
| 0.26~0.30 | 0.260~0.297 | 0.8453 | 0.9206 | 위반 |
| 0.22~0.26 | 0.220~0.259 | 0.7980 | 0.8985 | 위반 |
| 0.18~0.22 | 0.181~0.219 | 0.7549 | 0.8788 | 위반 |

스펙의 상관 요건을 지키는 한 `combined` 의 하한은 약 0.94 다.

## 4. 최종 설정과 결과

`latent_factor_strength = 0.85`, `generation_correlation = 0.31 ~ 0.35`

| 피처 그룹 | v1 | **v2 (최종)** |
|---|---:|---:|
| traditional_only | 0.8338 | 0.8338 |
| alternative_only | 0.9957 | **0.8963** |
| combined | 0.9998 | **0.9470** |

개별 상관은 0.3105 ~ 0.3455 로 SPEC §4 요건을 충족한다.

**목표 구간은 0.85~0.90 에서 0.90~0.95 로 정정했다.**
남은 0.94 는 누수가 아니라 전통 정보와 대안 정보의 상보성이며,
이는 본 프로젝트가 증명하려는 현상 그 자체이기 때문이다.

## 5. 씬파일러 유형 분화 (ADR-010)

v1 에서는 씬파일러 판정의 두 조건이 완전히 같은 집합이어서 SPEC §4 의 OR 정의가 형해화됐다.

| | v1 | v2 |
|---|---:|---:|
| 연체 컬럼 2개 이상 결측 | 45,000 | 31,471 |
| 거래 이력 12개월 미만 | 45,000 | 27,121 |
| **교집합** | 45,000 | **13,592** |
| **합집합 (= is_thin_filer)** | 45,000 | **45,000** |

유형 구성: `missing_only` 39.7% / `history_only` 30.1% / `both` 30.2%.

## 6. 전체 학습 결과 (검증)

> **이 절은 7세션 시점(`bias_ratio = 0.1`) 스냅샷이다.** 최종 데이터(`bias_ratio = 0.3`) 값은
> 리포트 5장(`docs/report/06_models.md`)과 8장(`09_anova.md`)을 따른다.
> 예: combined 최고 test AUC 0.9491 → 0.9460, 챔피언 0.9485 → 0.9453, Tukey p_adj 0.6137 → 0.6468.

보정된 데이터로 18개 조합 × RepeatedStratifiedKFold(5×4) = 360 fits 를 학습했다(616.4초).

| 피처 그룹 | 최고 test AUC | 조합 |
|---|---:|---|
| traditional_only | 0.8355 | xgboost / class_weight |
| alternative_only | 0.8975 | logistic_regression / smote |
| **combined** | **0.9491** | xgboost / smote |

> 최종 채택 조합은 test AUC 최고인 `xgboost / smote` 가 아니라 `xgboost / class_weight` (0.9485) 다.
> SMOTE 와의 차이(0.0006)가 CV 표준편차(±0.0024) 미만이라 유의하지 않고, SMOTE 는 합성 샘플로
> 학습해 거절 사유 설명에 부적합하기 때문이다(ADR-001 부기).
> 알고리즘 역시 XGBoost 가 LightGBM 보다 유의하게 낫다는 근거는 없다(Tukey p_adj=0.6137, ADR-012).

정정된 목표 구간 0.90~0.95 안에 들어온다.

씬파일러 유형별 uplift (XGBoost, traditional_only → combined):

| 세그먼트 | n | AUC 전통 | AUC 통합 | uplift |
|---|---:|---:|---:|---:|
| normal | 15,696 | 0.8548 | 0.9522 | +0.097 |
| thin: history_only | 2,084 | 0.8422 | 0.9445 | +0.102 |
| thin: missing_only | 2,704 | 0.7647 | 0.9374 | +0.173 |
| thin: both | 2,016 | 0.7417 | 0.9369 | **+0.195** |

**ADR-001 의 설계 의도가 데이터로 확인된다.** 전통 피처 정보량이 적을수록 대안 데이터 기여가 커진다.
`history_only` 는 연체 이력이 온전히 관측되므로 전통 모델 AUC 가 0.842 로 일반 집단과 비슷하고
uplift 도 +0.102 로 작다. 반대로 `both` 는 전통 AUC 0.742 로 가장 낮고 uplift 가 +0.195 로 가장 크다.
ADR-010 의 유형 분화가 없었다면 이 대비를 볼 수 없었다.

## 7. 한계

**실제 신용평가 모델의 AUC 는 통상 0.85 ~ 0.88 수준이다.**
본 프로젝트의 `combined` AUC 0.94 대는 실제 대안 데이터의 예측력이 아니라,
SPEC §4 의 상관 요건(0.3~0.5)을 부도율 6.68% 인 이진 타겟에 적용했을 때 나타나는
**시뮬레이터 구조에 기인한 상한**이다.

따라서 본 리포트의 절대 AUC 수치는 실무 성능의 추정치로 해석해서는 안 되며,
**피처 그룹 간 상대 비교**(전통 vs 대안 vs 통합)와
**집단 간 상대 비교**(씬파일러 vs 일반, 씬파일러 유형별)에만 의미를 두어야 한다.
